# ChatBot 2.6.0

2026-11-11，本机版本。

- 统一程序、源码标识、构建目录、启动脚本、归档根目录、Windows 文件属性与应用名称为 ChatBot。
- 同一数据目录只运行一个实例；再次启动会唤回已有窗口，避免重复采集和并发写入。
- 聊天区首次渲染最近 200 条，按需展开更早消息；完整记录仍保留在后端，分析范围不变。
- 聊天气泡按消息身份更新，状态变化不再重建整段聊天；保留滚动位置与未改变的媒体节点。
- 后端将短时间内的状态变化合并为一次快照；关闭程序时丢弃待发布状态。
- 修复模型进程启动失败时的管道泄漏，拒绝结构错误的桥接请求。
- 设置抽屉支持焦点约束、Escape 关闭与焦点返回；回复改写输入框保留输入位置。
- 新增 `--safe-start`，仅本次启动暂停自动分析、表情自动识别和自动回复恢复，不改写配置文件。

本轮验证使用合成记录和本机模拟模型服务。真实模型推理、真实联系人消息发送与 macOS 原生构建不在本轮验证范围内。
