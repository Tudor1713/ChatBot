# ChatBot 2.6.1

2026-11-14，Windows 修复版。

- 修复从本机数据库打开会话后，点击“填入微信”误报“请先连接本机微信数据库”的问题。启动和保存设置时同步读取来源，无需先开启后台观察；仍保留目标会话核验。
- 桌面快捷方式恢复 `--start-capture`；仅手动填入不会开启自动发送。
- 新增 GitHub 正式版更新提醒：启动约 12 秒后检查，运行期间每 6 小时检查；设置底部可手动检查并前往发布页。可关闭自动检查。
- 检查只读取公开版本元数据，不上传配置、密钥或聊天。网络失败不阻塞使用。
- 更新为手动下载与替换；退出程序后保留原目录 `data/`。下载的干净发行包不含任何本机数据。

本次验证使用合成记录、模拟发布响应和数据库只读连接。不调用收费模型、不对真实联系人发送消息。macOS 产物另由 CI 验证后发布；本次本地验证范围是 Windows。
