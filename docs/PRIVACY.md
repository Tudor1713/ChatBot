# ChatBot 数据说明

安装目录的 `data/` 保存配置、记忆、回复历史、会话设定及日志。API 凭证在 Windows 上使用当前用户 DPAPI；本机数据库连接仅使用已配置的访问凭证，ChatBot 不主动从微信进程提取密钥。

微信数据库以只读方式打开。模型分析会把所需上下文发送至用户配置的模型服务；自动分析、表情识别或自动回复开启后可能调用该服务。演示与内置自检只使用合成数据及本机模拟服务。

自动回复受名单、会话核验、时效和限额控制。发送能力在 Windows 上依赖当前微信与桌面状态。只有用户明确开启相应功能后才应执行；按键成功不等于对方已收到。

`--safe-start` 在本次启动关闭自动分析、表情自动识别及自动回复恢复，不更改保存的配置。`--screenshot` 只接受 `--demo` 模式，避免记录真实私聊窗口。

发行检查排除 `data/`、`work/`、`.venv/`、历史构建和临时文件。不要把本机运行目录直接上传或分享。源码扫描是模式检查，不能替代人工确认文档和素材。

版本检查通过 HTTPS 获取固定 GitHub 仓库的公开 Release 信息，不发送 API Key、数据库路径、聊天或设备标识；GitHub 会收到常规网络请求元数据（如 IP）。可在设置里关闭自动版本检查。
